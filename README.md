# Time-Varying-Latent-Mediation-Model
A Bayesian Analysis of Time-Varying Latent Mediation Model: Integrating Varying-Coefficient Structural Models With Latent Measurement

## model function code
  tvmediation.R: time-varying latent mediation model;  
  DynMed.R: time-varying mediation model.

## run code for tvm
  run_s1.1.R

## generation replication data for tvm
  gen_mediation.R

## template for Mplus
  template_MLM.txt;  
  template_sp10.txt;  
  template_sp20.txt;  

## run code for Mplus
  s1_mplus.R was used for template_MLM.txt;  
  s1_mplus_sp.R was used for template_sp10.txt and template_sp20.txt.

## analysis code 
  analysis_s1.R was used to analyze tvm;  
  analysis_sp.R was used to analyze seperated-time mediation model;  
  analysis_mlm.R was used to analyze multilevel mediation model;  
  analysis_number_decay.R, analysis_number_hump.R, and analysis_number_valley.R were used to analyze varying number and time-point.

## plot code
  plot_publish.R, plot_mediation_mlm, plot_mediation_sp.R, plot_number.R.
